EDENGUILT - THE COST OF PARADISE

Unzip the entire download before playing. No Godot installation is required.
Windows: double-click EdenGuilt.exe.
macOS: double-click EdenGuilt.app. This prototype is ad-hoc signed, not notarized;
if Gatekeeper blocks it, approve it in System Settings > Privacy & Security.

Enter advances the illustrated prologue. Esc opens settings and control help.
Settings supports English and Chinese. Use the game's nearby interaction hints.

PRESENTATION MODE
Open Demo Mode.cmd (Windows) or Demo Mode.command (macOS) to skip the prologue.
Ctrl+1: Junkyard. Ctrl+2: Toxic Mine. Ctrl+3: Eden City.
Ctrl+PageDown / Ctrl+PageUp: next / previous chapter.
The normal game launcher keeps these presentation shortcuts disabled.

BUILDINFO.json records the source commit and Godot version for this build.
