# 角色动作与流程回归

主战役 F5 运行后自动使用双形态动作；原几何测试房和近战模板房保留旧占位造型。
每种形态有 24 个独立姿势，动作表来自内置 image_gen，沿用现有角色设计。
生成资源在 `assets/art/generated/animations/`，完整提示词见 [生成记录](character-action-prompts.md)。

| 图集行 | 六列帧（从左向右） |
| --- | --- |
| 1 | 跑步循环 1–6 |
| 2 | 待机、呼吸、起跳、二段跳、下落、落地 |
| 3 | 短砍前摇、短砍命中、短砍收招、长砍前摇、长砍突刺、长砍收招 |
| 4 | 举盾、持盾、矿化施法、黑穿、受击、倒地 |

E 学习、R 卸载复用施法姿势。移动、跑步、朝向、跳跃由真实玩家物理状态驱动；
刀光与击中特效来自近战组件的实际阶段和命中信号，不改变攻击范围或重复计算伤害。
护盾、矿化、黑穿和受击中断近战，拒绝的技能不播放成功动作。
动作图集按固定格取帧，使用脚底基准修正举盾/倒地悬空；不改角色碰撞体。

`HeroActionVisual` 只负责画面。剧情选择暂停角色动作和粒子；死亡后仅允许倒地画面继续，
地图、伤害、移动、计时及碳账本保持终止状态。检查点继续时创建新的动作实例，保留剧情决定的形态。
