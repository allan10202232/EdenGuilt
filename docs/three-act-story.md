# 三幕、双语与毒素谜题

本轮沿用哥特 UI、四套敌人动作、技能碳账本及 A/B 结局，加入可实际游玩的剧情与学习环节。

| 关卡 | 独立场景 | 主要目标 |
| --- | --- | --- |
| 垃圾场 / Junkyard | `scenes/campaign/junkyard_start.tscn` | 向莫斯询问道路，汇聚绿色学二段跳，越过断崖 |
| 毒雾矿坑 / Toxic Mine Pit | `scenes/campaign/toxic_mine.tscn` | 听取矿工线索，学习矿化，按编号封住毒源、打开净化门 |
| 伊甸城 / Eden City | `scenes/campaign/eden_city.tscn` | 学盾和黑穿，击败守卫，发现真相，选择 A 返程修复或 B 留在城内 |

旧内部地区 ID 和 `eden_garden.tscn` 保留兼容；新版主战役使用 `eden_city.tscn`。

## 开场

采用 main 新增的四幕像素开场：吸魂器 → 伊甸环城 → 地下矿区 → 主角拾起吸魂器，八句英文旁白由 Enter 逐句推进。
前三幕逐像素显现、第四幕缓慢淡入，转场期间与长按重复输入均不会跳过旁白。开场期间尚未创建关卡，不推进时间或碳账本。
最后一次 Enter 仅启动一局游戏。旧三幕开场及菜单后的播放入口已移除，死亡继续、Restart 或返回主菜单重玩均不重复播放；重新运行项目才重播。

## 语言

新用户默认 English，English / 简体中文选择保存在 `user://preferences.cfg`。
菜单、HUD、NPC、死亡、真相、审计页均可切换；动态数值、技能/地区名、检查点及通知随语言更新。四幕开场保留 main 的英文旁白与美术。
审计 HTML 按导出时语言生成，JSON 附带 language；游戏内切换语言不会重复导出文件，重新导出按钮生成当前语言版本。

`GameText` 在其余单例之前注册，`localization/strings.tres` 是打包依赖，`strings.json` 是同内容的可读编辑源。
修改 JSON 后运行 `python localization/compile_catalog.py` 同步生成 tres；游玩时不需要 Python。界面字形使用 Georgia / 宋体与中文后备字体。

## NPC

每关入口有一名非碰撞居民：莫斯（拾荒者）、艾拉（矿工）、赛恩（守档人）。靠近按 T 对话。
文字逐字显示，Enter / T 或继续按钮先显示完整句子，再前进；Esc 或结束按钮离开。
对话期间角色、敌人、危险区、计时与碳账本暂停。结束确认经过输入缓冲，空格不会同时触发跳跃。
居民交谈提供线索，不作为硬性进度条件；返程后改为共同修复的对话。

## 大地余绿与技能学习

可站立表面散布小苗与绿色叶片，随风摆动。在能力源按 E 后，附近 680px 内的绿色沿弧线聚集到角色，角色播放施法动作。
1.5 秒汇聚期间暂停玩法，完成时才授予能力；额外 0.75 秒显示新能力并散去余光。学习本身不记排放，使用技能按原规则记账。
借用能力后周围绿色衰减、土地白化；返程修复和交还后绿色恢复。重复按 E 不再播放仪式，也不重复授予或记账。
旧 A/B 联调接口仍可直接调用 `WorldProgress.borrow_ability`；玩家实际 E 交互经过 `LearningRitual`。

## 矿洞毒素谜题

三个节点有清晰的 I / II / III 标记，矿工给出顺序：

1. I：在断口前矿化，固定晶桥。
2. II：固化上游毒源。
3. III：固化下游毒源。

未固定前一节点时，后续节点拒绝施法并提示，不产生碳排放或固碳信用。
每个成功节点 +1kg 模拟排放，并单列固定 15kg 模拟 CO₂，不能重复领取。
三个节点均固定后，出口净化门失去碰撞且允许转场；仅靠跳跃绕过门体无法绕过解谜条件。
节点与门状态沿用本局 collect ID，死亡继续、离开重入都保留，开启新一局才重置。返程共同修复也会解除门与毒源。

未处理喷口持续逸散低浓度毒素，喷发时浓度升高，原喷发伤害仍存在。
毒素负荷低浓度 +8%/秒、喷发 +46%/秒，离开后 -22%/秒；75% 以上每秒尝试造成半颗生命球的中毒伤害，与 main 的统一受伤规则一致，仍遵守受击无敌间隔。
HUD 显示负荷与封印计数；这些均为虚构游戏机制，不代表现实毒理或排放计算。
