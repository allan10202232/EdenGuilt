# 三关状态面板、坠落扣血与矿脉抽取

2026-10-18：统一生产战役的三关界面和生命规则，并将第二关能力获取接回真实吸取动作。

## 统一面板与备份

`scripts/ui/chapter_status_hud.gd` 是三关共用的第二关样式组件，左上角位置为 (20, 18)。生命球观察 `GameSession`，排放与碳固定观察 `CarbonLedger`，关卡脚本只提供段落、跳跃和技能状态。第一关旧跑酷面板、主 HUD 的旧顶栏与碳仪表盘均不再重复显示；设置菜单保留在右上角。

修改前的八份界面、主题和矿坑脚本保存在 [`../backups/hud-before-unification-20261018/`](../backups/hud-before-unification-20261018/README.md)，对应原始提交 `70aa8f0`。备份目录带 `.gdignore`，不会向 Godot 注册重复脚本类。

## 生命规则

- 共 100 HP，五颗绿色生命球；普通受伤扣 10 HP，即半球。
- 坠入酸池扣 20 HP，即整球；第一关压机底齿的检查点救回也扣整球。
- 扣血基于当前生命：90 → 70 → 50 → 30 → 10 → 0。检查点和自动救回不补血。
- 非致命坠落快速回到当前检查点；能力、场景进度与碳账本保留。
- 血量归零进入 Game Over；主动选择“从检查点继续”或重新开始，才恢复生命。

统一扣除入口为 `GameSession.apply_fall_penalty()`；三个关卡控制器负责各自的瞬间回位、平台重置和视觉表现，不再各自设置满血。第二关独立 F6 试玩同样支持 Game Over。

## 第二关抽取

矿坑入口 X=420 增加 `MineLifeSeam`，复用洞窟已有岩石、矿石图集，并以微光苔藓和矿层细线表现生命。站稳靠近后按 E，播放约 2.4 秒原版六帧吸取动作：下蹲引流、举起充能、收起装置。矿脉微光逐步消失，完成后才获得碳矿化能力。E / J / C 随后恢复为毒雾固化操作。

吸取期间冻结移动、伤害和游戏计时；重复按键不重复授予能力。已吸取状态跨死亡、跨场景保留；中途离场会取消未完成动作。A 结局返程在入口按 R 共同修复，矿脉恢复，交还矿化能力。

双击根目录 `试玩第二关.cmd` 可直接检查入口吸取、统一面板与坠落扣血；正常 F5 流程仍从开场和第一关开始。
