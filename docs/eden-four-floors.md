# Chapter 03 · EDEN：四层上升与培养舱救援

第三关生产入口为 `scenes/eden/eden_chapter.tscn`，战役别名 `scenes/campaign/eden_city.tscn` 指向它。矿坑出口仍连接此关。双击根目录 `试玩第三关.cmd`，或打开 `scenes/eden/play_eden.tscn` 按 F6，即可从第三关开始；这个预览只预先提供前两关已获得的二段跳、碳矿化和试玩光刃，不提前提供护盾与黑冲。

## 与前两关的兼容约定

- 全部章节继续使用同一个 `ChapterStatusHUD`、五颗绿色生命球和碳账本。普通受伤扣半球，坠落扣整球，非致命坠落在 0.2 秒后回当前检查点，不补血。零血进入 Game Over，主动选择继续才恢复生命。
- 新第三关控制器继承矿坑的角色、美术、抽取动作、近战和基础运动接口；第三关重写盾能量与冲刺，不改第一关和第二关的控制逻辑。
- 保留原有结局编号：**A 是循环救援，B 是加入伊甸**。附件中的 A/B 字母含义与现有项目相反，因此采用其分支行为，并保留游戏已经建立的字母含义。
- 第三关救出三人后，在 1F 入口 R 共建修复并交还护盾、黑冲，T 离开。二段跳和矿化保留到各自原场景交还，继续连接矿坑、垃圾场的已有返程，最后在家园触发全局真结局。这避免将前两关返程截断。
- 拆除核心不会自动增加获救人数。循环模式从 `0 / 3` 开始，三只培养舱各有独立的持久化救援状态。

## 四层与节点

地图宽 2400 px、高 2600 px。碰撞与背景分开配置；背景插画里的台阶与管道不会产生看不见的碰撞。

| 层 | 节点 | 实际玩法 |
| --- | --- | --- |
| 1F 天堂入口 | 01 | 从右下进入，向左阅读生命之树和“仅统计城界内”的零排放公示，沿四级台阶上升；没有起始敌人 |
| 2F 荣升花园 | 02 | E 抽取护盾；三个不同高度的光接收器，需跳跃对齐并精准弹反；三灯点亮后开启花园桥 |
| 2F 荣升花园 | 03 | 净园执事：能量弹、地面光波与带预警的短程冲锋；反射两弹击碎护甲，眩晕后近战击败 |
| 2F 荣升花园 | 04 | 右侧 T 操作荣升电梯；看到朋友被封进培养舱，再进入处理层 |
| 3F 人体处理 | 05 | 从维护根系吸取黑冲，穿过不能靠普通跳跃越过的相位墙 |
| 3F 人体处理 | 06 | 进入密封舱室，左键切断供能管，打开内侧出口，机械师奥伦离开；返程在这里救培养舱 2 |
| 3F 人体处理 | 07 | 反射炮塔弹充能第一扇门；6 秒内经过门并黑冲穿越第二道相位墙；失败可反复重新充能 |
| 3F 人体处理 | 08 | 五级毒雾接力竖井：E 矿化、二段跳、相位穿越与挡弹结合；晶台持续 4 秒，最后 1 秒摇晃闪烁 |
| 4F 生命熔炉 | 09 | 圆顶战场、核心抽取装置、左右生物供能管、上层台与相位分区 |
| 4F 守护协议 | 10 | 反射 3 弹打开核心护壁，暴露 20 秒并暂停发弹；矿化下方毒雾并跃起攻击抽取装置，转入第二阶段 |
| 4F 掠夺协议 | 11 | 守卫全场冲锋；黑冲穿过身体，撞墙硬直 5.4 秒，期间接触安全，绿色光环及 HUD 倒计时提示反击窗口 |
| 4F 收割协议 | 12 | 左侧高台盾反切断供能线；右侧矿化→二段跳→黑冲上平台，近战切断抽取锁 |

目标是拆除树心周围的生命抽取机器。树和原始场景插画保留。

净园执事第一次弹反只提示装甲开裂、还需一次；破甲后轻击与重击均可扣血。核心与冲锋守卫的装甲状态、反击倒计时显示在 Boss 血条下；无效攻击会解释当前破防方式。冲锋锁定朝向，动画依次进入蓄力、持续冲锋、撞墙硬直和恢复，受击停顿与画面同步。

双击 `试玩第三关Boss修复.cmd` 可直接测试最终战，预先提供本章所需能力。此入口是独立新局预览，不改变正常开场和正式关卡进度。普通第三关入口仍为 `试玩第三关.cmd`。

## 操作与能力

| 操作 | 按键 / 规则 |
| --- | --- |
| 移动与跳跃 | A/D 或左右；空格跳跃、空中再按二段跳；速度 260，重力 980，跳跃 -420 / -390，宽限与缓冲各 0.12 秒 |
| 碳矿化 | E / C / J，半径 260；能力源附近 E 优先播放约 2.4 秒吸取动作 |
| 持盾 | 按住 Q / K；每秒扣 28 能量，普通挡弹每颗再扣 8；移动为 65% |
| 精准弹反 | 命中前 0.18 秒内起盾；无额外挡弹消耗、恢复 25 能量、反射速度为原来的 1.6 倍、短暂停顿 0.06 秒 |
| 护盾恢复 | 上限 100，松开 0.8 秒后每秒恢复 25；耗尽过热 1.5 秒，须松开恢复 |
| 黑冲 | Shift / L / F；速度 680，持续 0.22 秒、冷却 0.75 秒；空中一次，落地刷新 |
| 冲刺穿透 | 冲刺只临时关闭相位墙层（16），普通地形和实体能源门仍阻挡；冲刺中免疫敌人身体接触伤害 |
| 光刃 | 左键轻击、右键重击；三关鼠标攻击保持一致，判定框默认隐藏，教学测试房可以单独显示 |
| 交互 | T 阅读公示 / 电梯 / 出口；下 + 空格穿过单向台向下落；救出三人后在 1F 入口 R 修复交还 |

弹反的角色顿帧计时会随物理帧归零，重生与剧情移位清理顿帧和挥砍状态。移动、绿色形态、攻击收招及刀光粒子不会因旧弹反停顿而永久冻结。

三人救齐后，一层右侧入口常驻提示先 R 修复、再 T 回矿坑；按 T 时若尚未修复，会解释缺少的 R 步骤。目标 HUD 和场景提示在修复后同步切换为 T 离开，护盾与黑冲显示为已交还；攻击不会触发离开。修复和离开共用距入口 250 px 的范围，平台右端也可操作。

技能实际生效时沿用现有排放规则。有效矿化批次单列教学模型碳固定 150 kg CO₂e，不从累计排放中删除历史。盾能量是战斗资源，和生命球、碳账本分别显示。

## 选择与救援

核心三个阶段完成后才显示结局选择；处理中打开设置或切换字幕不会跳过战斗。

- **B 加入伊甸**：直接进入现有妥协结局与审计报告，不伪造救援或修复数量。
- **A 循环救援**：返回核心层安全台，亲自重复右上方能力组合路线，开始下降救援。

| 顺序 | 位置 | 救援方式 |
| --- | --- | --- |
| 1 | 4F 右上平台 | 矿化、二段跳、穿过相位分区，再精准弹反击碎生物锁 |
| 2 | 3F 奥伦舱室 | 抵挡警戒炮塔，黑冲进入封闭舱室，左键打破阀门 |
| 3 | 2F 荣升电梯上层 | 二段跳升上吊舱平台，黑冲穿过隔墙，反射炮弹过载电梯生物锁 |

每释放一只培养舱才增加一次人数，重复操作不加分。获救居民加入同行队列；该舱警戒炮塔失去电源。Game Over 继续后保留已救培养舱、已拆核心、能力与账本，避免重做救援或人数跳变。三人齐全后先停用危险、打开公共下降路线，再允许在入口交还技能。

## 美术与结构

原始文件按原样保存在 `assets/art/originals/eden/`：`paradise.jpeg`、`processing.jpeg`、`blueprint.png`。1F–2F 使用用户的 `Eden 1-2.jpeg`，3F–4F 使用用户的 `scene 03bg.jpeg`。下层平台复用藤蔓白石，上层从处理穹顶原画的金属走道取材；培养舱、能源门与设备使用像素绘制，人物与敌人复用已接入动画，不依赖付费资产。
