# Level 1 · Scrapyard Parkour

第一关入口仍是 `scenes/campaign/junkyard_start.tscn`，由正常开场和菜单进入，完成后连接毒雾矿坑。
直接试玩可运行 `scenes/parkour/play_scrapyard.tscn`（Godot F6），跳过开场直接开始新的一局。
单独检查压机可双击 `试玩压机调整.cmd`，或运行 `scenes/parkour/play_crusher_section.tscn`：从第五段安全台开始，预先提供二段跳。
独立入口使用真实战役、HUD、吸魂器和碳账本，不另建一套人物或关卡逻辑。

## 路线

| 段 | X 范围 | 内容 | 二段跳用途 |
| --- | --- | --- | --- |
| 1 | 0–1500 | 安全起点、绿洲、五块 0.45 s 塌台 | 救回迟跳、横向跨越或跳过中间平台 |
| 2 | 1500–3000 | 三条传送带、64 px 落脚点、带落点预警的废铁 | 脱离逆向拉力，空中调整落点 |
| 3 | 3000–4400 | 从 Y=650 向 Y=180 的废料塔，0.6 s 倾斜台 | 前三层每次上升 140 px，单跳不可达，需空中追加跳跃 |
| 4 | 4400–6200 | 五台磁铁、下层塌台、四块上层小台 | 第一台到达 Y=240 后起跳进入高处路线；下路在 Y=520 附近穿行 |
| 5 | 6200–7800 | 两台压机、48 px 易碎台 | 提前离开塌台，延后第二跳，在空中等待下压结束 |
| 6 | 7800–9600 | 七块 0.3 s 塌台、向 Y=320 抬升的出口 | 连贯横向跳跃、最后一跳登上出口 |

第一台磁铁行程 380→240 px，其余纵向磁铁行程 520→380 px。这样下层平台到下一台磁铁的高度差不超过二段跳能力。
第二、四台磁铁横向移动，位移 140 px，周期 2.4 s。双路线共用同一个第四段检查点。
高处和下方路线只提供不同的跳跃挑战，不再放置钱币式收集物、生物炭奖励或额外加分提示。

## 人物与失败恢复

第一关独立运动配置：速度 260，重力 980，地面跳跃 -420，二段跳 -380。
垃圾场与矿坑使用固定跳跃弧线；伊甸城沿用原有轻重跳和 Shift 快跑。
二段跳重置垂直速度；按方向键时获得持续 0.24 s 的 1.15 倍水平速度，并出现绿色像素爆发环。
离地宽限和落地输入缓冲均为 0.12 s。只有真正的空中追加跳跃记 5 kg 教学模型排放。

各段入口有永久安全台和垂直检查点触发区；上层路线也能更新检查点。
Y>900 的酸池和压机底齿命中扣一整颗生命球（20 HP），保留原有伤势；仍有生命时原地转回该段安全台，不重新加载场景。
重生当帧恢复跳跃、重置塌台与落物，并增加死亡/重生计数；生命保持扣除后的数值，能力、得分和碳账本保留。检查点不补血。
普通废铁碰撞仍扣半颗绿色生命球。三关血量耗尽均进入 Game Over，只有主动选择继续才恢复满血。
对话和抽取动作会暂停机关、磁铁 Tween、人物和计时。

左上角使用三关共用的第二关样式 HUD，提供绿色生命球、段号与名称、空中追加跳跃状态、能力状态、死亡/重生计数、累计排放和碳固定。原跑酷 HUD 已备份，生产场景不再重复显示它。
荒芜滤镜让余绿渐变成暖麦黄并保持画面明度；摇晃、方向箭头、落点线、蒸汽和闪烁同时提供形状/运动提示。

酸水使用独立的 `scripts/parkour/toxic_water.gd` 与 `scrapyard_water.gdshader`：像素阶梯波面、分散泡沫、上浮气泡及水深流动纹理。水体向镜头外延伸，不再露出原先 120 px 色块的平直底边。纯表现组件不参与碰撞，仍沿用 Y>900 的坠落扣血与重生规则；暂停时波面、流动和气泡一起停止。

| `scenes/parkour/fragile_tilt_platform.tscn` | 承重 0.6 s，画面倾斜后塌落 |
| `scenes/parkour/magnet_lift.tscn` | 物理 Tween 驱动的横/纵向磁铁，自动承载玩家 |
| `scenes/parkour/hydraulic_crusher.tscn` | 0.5 s 预警、0.15 s 下压、0.4 s 停留、1.2 s 回收、2.25 s 安全等待；完整周期 4.5 s |
| `scripts/ui/chapter_status_hud.gd` | 三关共用的第二关样式状态面板；原跑酷 HUD 已停用并备份 |
| `scripts/placeholder_player.gd` | 共用 CharacterBody2D，运动参数由场景指定 |
| `scenes/campaign/base_region.tscn` | 原战役公共结构，矿坑和旧伊甸园场景继承它 |

五类机关都可以独立拖入场景，在检查器调整宽度、延时、传送方向、运动方向或周期。
所有平台复用 `assets/art/generated/scenarios/junkyard_terrain.png` 的透明废料悬台材质，统一锈铁、旧木、轮胎与苔藓配色；顶边与实际碰撞面齐平。
塌台保留摇晃、橙色裂纹和进度条，传送带保留运动箭头，磁铁改用旧钢架和链条，只用小型青绿指示灯标识。
压机同步改为锈蚀机壳、旧警示漆和金属齿；下砸与底部停留时仅最下方齿面判伤，压头两侧和主体不判伤，抬起时安全。
齿面与玩家头部使用相对扫掠检测，既防止快速下砸穿过玩家，也避免水平擦边触发伤害。

## 返程兼容

选择 A 并从矿洞返回时，居民会架设贯穿六段的连续缓坡步道，停用所有跑酷机关。
步道与每块永久台顶面齐平，可从出口步行回到绿洲，按 R 共同修复并交还二段跳，再向左回家。
返程时出口不会把刚回到第一关的玩家立即送回矿洞。
