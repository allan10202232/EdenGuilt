# 演示跳关

双击仓库根目录的 **演示模式.cmd**，或在 Godot 打开 `scenes/demo/presentation.tscn` 后按 **F6**。会直接开始第一关，跳过开场旁白。

先点一下游戏画面，让游戏获得键盘焦点：

| 快捷键 | 功能 |
|---|---|
| Ctrl + PageDown | 下一章：垃圾场 → 矿坑 → Eden City |
| Ctrl + PageUp | 上一章 |
| Ctrl + 1 | 第一章垃圾场入口 |
| Ctrl + 2 | 第二章矿坑入口 |
| Ctrl + 3 | 第三章 Eden City 入口 |

笔记本没有独立 PageUp / PageDown 时，直接用 Ctrl + 1 / 2 / 3 最方便。Esc 设置中也会显示这些快捷键。

跳关复用原有的黑屏渐变、玩家工厂与镜头定位。进入矿坑时补齐二段跳；进入伊甸城时补齐二段跳、碳矿化。当前章节的能力仍可正常吸取；已获取的能力、生命、碳账本、战斗与剧情状态保留，不会凭空加分、击败 Boss、救出居民或选择结局。A 结局返程仍沿用原有返程状态和安全通路。

剧情字幕、抽取能力、设置暂停或正在切关时，快捷键暂时无效；完成或关闭后即可使用。第三关不会自动循环到第一关，避免讲解时误触。

正常 **F5** 主线不启用跳关。也可在 Main 的 Inspector 勾选 `demo_shortcuts_enabled`，或启动时追加用户参数 `-- --demo`，为当前主场景开启快捷键。

现有的 **试玩第三关Boss修复.cmd** 可以直接检查最终战；**试玩第二关.cmd**、**试玩第三关.cmd** 仍可分别独立启动对应章节。
