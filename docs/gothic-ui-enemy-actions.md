## 敌人动作

`assets/art/generated/animations/` 中新增四张动作表：机械拾荒者、晶矿兽、苔木爬行兽、伊甸守卫。
每张 6 列 × 4 行、24 个姿势，透明背景，统一朝右，向左行走时镜像。矿兽图原始宽 1535px，其余 1536px；
Sprite2D 按实际纹理宽度等分取帧，不假设每格都恰为 256px。UI 图集原始尺寸为 1254 × 1254，也按实际尺寸取格。

| 索引（从 0 开始） | 动作 |
| --- | --- |
| 0–5 | 六帧行走，狂暴时加快 |
| 6–7 | 待机与呼吸 |
| 8–10 | 三阶段攻击蓄力 |
| 11–14 | 出手、延伸与收招 |
| 15–17 | 受击与踉跄预留 |
| 18–21 | 蹲伏、起跳、下落、落地 |
| 22–23 | 倒下与尸体 |

`EnemyActionVisual` 只负责画面，机械敌人的弹丸与守卫重击仍在蓄力结束时生成/结算一次。
守卫使用独立的古木骨甲造型，地面荆棘环对应左右 255px 重击范围，收招 0.34 秒时停步；
0.75 秒蓄力、原伤害和攻击冷却保持不变。守卫不再继承普通爬行兽的随机跳动。
爬行兽每次跃起前先蹲伏 0.15 秒，再播放起跳、下落和落地姿势。矿兽保留巡逻与接触伤害，不添加新攻击判定。

敌人死亡立即移除原碰撞实体并结算分数/剧情；分离出的无碰撞视觉节点继续倒地、淡出，0.62 秒后销毁。
剧情对话暂停活敌人的动作和 AI；已死亡的视觉节点仍可清理，不会挡住通路或重复计分。

原美工文件与旧单帧素材均保留。新增素材使用内置 imagegen；准确提示词与所有保存路径见 [生成记录](gothic-ui-enemy-prompts.md)。
