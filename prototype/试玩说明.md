# 地脉固化：第一版闭环原型

在 Godot 项目管理器点击“导入”，选择本目录中的 project.godot，打开后按 F6 运行当前场景或 F5 运行项目。

- A/D 或方向键：移动。
- 空格：跳跃；抽取后在空中再按一次可二段跳。
- E：站在节点附近长按 1.5 秒交互。
- R：清空进度并重新开始。
- Enter：推进剧情文字。文字显示期间暂停人物操作。
- F：在旧手环附近检视环境线索。
- Shift 或 K：越过断崖后解锁冲刺，按方向决定冲刺朝向；不按方向时沿人物朝向冲刺。

流程：向右在孤木抽取 → 观看枯竭演出 → 二段跳跨过断崖 → 抵达伊甸入口发现被抽取的伙伴 → 长按 E 开舱救出三人 → 带他们向左返回断崖右岸接收器 → 交还能力升起树桥 → 和三人一起回到左侧起点。

掉落只重置位置，保留当前剧情与能力。返程接收器和生态恢复是验证玩法的临时设计，不代表正式剧情设定。

第二版增加：开场与关键节点短剧情、旧手环检视、斗篷人物、远景与浮尘、能力状态显示、检查点反馈、能力变化光环。第一版保存在 D:\EdenGuilt\backups\prototype-v1。

试玩重点：Enter 推进是否清楚、文字是否遮挡或溢出、F 检视能否发现、抽取与交还后能力变化是否容易理解。暂未加入战斗、音频、磁盘存档与正式双结局。

第三版：强化抽取时的白化、落灰、池水结盐与鸟声中断；开舱救援是主动交互，伙伴以简化的无碰撞跟随方式移动，在未搭桥的断崖前停下，全部回家才触发结束。返程不会让原树恢复绿色。已加入临时合成鸟声和抽取音效，尚无正式配乐；不增加倒计时或伙伴受伤惩罚。第二版备份在 D:\EdenGuilt\backups\prototype-v2。

## 第四版：动作与炮台测试

- 普通跳跃增加 0.10 秒离地容错、0.12 秒落地前输入缓冲，二段跳规则不变。
- 第一处断崖右侧自动启用独立测试冲刺模块，并出现教学。Shift/K 冲刺持续 0.24 秒，从启动时计算 0.85 秒冷却；空中也能使用，冲刺期间免疫炮台伤害。
- 炮台循环：1.2 秒熄灭、1 秒黄光预警、0.7 秒红光发射、0.9 秒熄灭。站在光束边缘冲刺可穿过整个危险区，也可以等待发射结束再走。
- 三格生命；受击后 1 秒无敌并短暂击退。生命耗尽或掉落即回检查点，恢复生命、清除冷却，保留能力与剧情。炮台前后各有安全检查点。
- 救出伙伴后切断炮台供能，危险区以绿色标示为安全道路；返程仍需要交还二段跳搭桥。测试冲刺模块独立保留，不算新的正式绿洲能力。
- 第三版备份在 D:\EdenGuilt\backups\prototype-v3。

试玩重点：能否看懂黄光和红光、冲刺的距离与冷却是否舒服、受击原因是否清楚、失败后是否愿意重试。暂未制作近战、小怪、Boss、正式配乐与磁盘存档。

第四版提示调整：炮台上方显示即将发射、发射伤害说明和停机状态，不显示倒计时；黄框与红框加强显示。生命使用实心/空心圆点表示，是每次尝试的 3 点生命，不是 3 次机会；可无限重试，无 Game Over。
