# EdenGuilt

> 仓库根目录是独立的系统验证工程；此前制作的《地脉固化》可玩原型保存在 [`prototype/`](prototype/)。在 Godot 中导入 `prototype/project.godot`，按 F5 运行。原型的操作和流程见 [`prototype/试玩说明.md`](prototype/试玩说明.md)。

横版 2D 类恶魔城项目，Godot **4.7.2 / GDScript / GL Compatibility**。
程序员 B 第一阶段已依据 [Rules and Ability 原文](docs/design-rules.md)补齐能力状态、检查点和世界进度接口。

## 打开和试玩

在 Godot 导入根目录 `project.godot`，按 **F5**，点击“开始游戏”。

| 操作 | 输入 |
| --- | --- |
| 左右移动 | A / D 或 ← / → |
| 跳跃 / 已获得后的二段跳 | 空格 |
| 快跑 / 已获得后的冲刺 | 按住 Shift / 按下 Shift |
| 已获得后的护盾 | 按住 Q |
| 已获得后的光刃 | 鼠标左键 |
| 吸收 / 交还 | 靠近能力源后按 E / R |
| 光刃接口试用（获取地点待定） | 调试版本按 F1 |

去程为 **孤木 → 草原 → 残海**：每个场景左侧蓝色能力源依次提供二段跳、冲刺、护盾。
吸收后对应土地变荒芜。穿过场景最右侧绿色门进入下一场景，并自动建立入口检查点。
到残海最右端开始返程，再回各自能力源交还；失去能力后会生成步行通路，残海还会产生保护屏障。
交还三种已确定地点的能力后，从孤木最左端离开，触发验证关卡胜利。

金色碎片各加 100 分，尖刺每次扣 25 生命，方块怪一击击败。死亡或坠落后，弹窗提供：

- **从检查点继续**：回到最近场景入口，恢复生命；保留得分、能力、交还状态、已击败怪物和已拾取碎片。
- **重新开始整局**：重置全部本局进度。
- **返回主菜单**：结束当前游玩；下次开始建立新的一局。

## 阶段一交付

- [x] 主菜单、场景切换、死亡/胜利结算、检查点继续和整局重开。

- [x] 获得/交还能力与去程/返程的世界状态，光刃交还前检查撤离通路确认。
- [x] 跨场景及死亡后的怪物不刷新、碎片不重复计分。
- [x] SoundManager 的音效池、BGM、音量、静音及能力/检查点事件接口。
- [x] 真实 UI 输入、物理碰撞、跨场景及检查点恢复的自动化验收。

三个场景共用一套几何占位房间；动作和静态方块怪仅用于验证接口，正式角色、战斗、AI、关卡和美术仍待对应负责人接入。
Q/E/R 的临时映射已由用户确认；光刃获取地点、交还地点和正式战斗平衡仍未定义。
当前进度保存在内存中，不提供跨进程存档。满血恢复和保留得分属于文档未规定部分的临时实现策略。

详细接口见 [程序员 B 交接文档](docs/programmer-b-phase-one.md)和[能力与检查点接入说明](docs/ability-system.md)。

## 自动化验收

在仓库目录运行（替换为本机的 Godot 控制台程序路径）：

```powershell
.\tests\run-tests.ps1 -Godot 'C:\Tools\Godot_v4.7.2-stable_win64_console.exe'
```

增加 `-Screenshots` 会启用真实渲染并保存主菜单、HUD、死亡、返程和胜利截图：

```powershell
.\tests\run-tests.ps1 -Godot 'C:\Tools\Godot_v4.7.2-stable_win64_console.exe' -Screenshots
```

也可直接运行：

```text
godot --headless --path . --editor --import --quit
godot --headless --path . --audio-driver Dummy res://tests/phase_one_test.tscn
```

验收程序在检查失败、引擎错误或警告时返回非零退出码。
生成的导入缓存、日志和截图位于已忽略的 `.godot/`、`test-output/`。
